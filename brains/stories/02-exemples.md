# Exemples de stories

Huit exemples qui respectent la ligne éditoriale (titre ≤ 32 caractères, affiché en capitales ; texte ≤ 160 caractères ; vouvoiement). Le CTA principal est « Envoyez ENGLISH en DM » (`ctaKeyword`) ; « Réservez votre entretien (lien en bio) » sert à varier.

## 1. Erreur fréquente

```json
{
  "template": "erreur",
  "title": "Stop saying « I am agree »",
  "body": "« Agree » est déjà un verbe : pas besoin de « am ». On dit simplement « I agree » ou « I don't agree ».",
  "cta": "Vous la faisiez ? 😉"
}
```

## 2. Astuce du jour

```json
{
  "template": "astuce",
  "title": "Gagner du temps pour réfléchir",
  "body": "Bloqué(e) en réunion ? Dites « That's a good question, let me think » : vous gagnez quelques secondes, avec naturel.",
  "cta": ""
}
```

## 3. Erreur fréquente (faux ami)

```json
{
  "template": "erreur",
  "title": "« Actually » ≠ actuellement",
  "body": "« Actually » veut dire « en fait ». Pour « actuellement », dites « currently » ou « at the moment ».",
  "cta": "Enregistrez pour vous en souvenir"
}
```

## 4. Question / quiz

```json
{
  "template": "question",
  "title": "Vous diriez quoi ?",
  "body": "« Je travaille ici depuis 3 ans » : A) « I work here since 3 years » B) « I've been working here for 3 years »",
  "cta": "Réponse demain"
}
```


```json
{

  "title": "Écoutez ce que vous comprenez",
```

## 7. Peur de parler

```json
{
  "template": "citation",
  "title": "Peur de faire des fautes ?",
  "body": "Vous en savez sûrement plus que vous ne le pensez. Ce qui bloque, c'est souvent la peur de l'erreur, pas le vocabulaire. Chez nous : zéro jugement.",
  "cta": "Partagez à qui en a besoin"
}
```

## 8. Invitation à l'entretien

```json
{
  "template": "appel",
  "title": "Vous comprenez mais bloquez ?",
  "body": "Faisons le point sur votre anglais lors d'un entretien avec notre équipe, gratuit et sans engagement. Votre niveau n'est que votre point de départ.",
  "cta": "Réservez votre entretien (lien en bio)"
}
```
